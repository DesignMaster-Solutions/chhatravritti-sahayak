# Chhatravritti Sahayak

Free, open-source helper for students from poor families in India: it tells a Class 11, ITI,
diploma, college or university student which government scholarships they can apply for this
year, where to apply (the National Scholarship Portal or their state's portal), by when, with
which documents, and the checks that keep an approved scholarship from getting stuck before it
reaches the bank account. English and Hindi.

Status: **not built yet.** This repository holds the scope (`BRIEF.md`) for an entry in the
Code for a Billion 2026 hackathon, track Education. Every rule, income ceiling and deadline the
tool will state is being checked against the official scheme guidelines and scholarships.gov.in
before it is coded; nothing here is advice yet.

Planned: static web app (English and Hindi, under 100 KB, no account, no cookies), rule engine
with tests, anonymous public usage counter at `/stats`.
